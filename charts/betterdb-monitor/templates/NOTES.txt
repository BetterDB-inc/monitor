{{- if not .Values.db.host }}

No database is configured (db.host is empty). Add your Valkey/Redis connection
in the UI, or set db.host / db.password in values and upgrade the release.

{{- if eq .Values.storage.type "memory" }}

Storage is in-memory: monitoring history is lost when the pod restarts.
For durable history, set storage.type=postgres and storage.url (or
storage.existingSecret) to a PostgreSQL connection URL.
{{- end }}

{{- if gt (int .Values.replicaCount) 1 }}

WARNING: replicaCount > 1. The monitor keeps per-process state (capture
sessions, in-memory storage); run a single replica unless you know why not.
{{- end }}
