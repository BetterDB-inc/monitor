The BetterDB plugin for OpenEverest is installing as {{ include "betterdb-openeverest.fullname" . }} (image {{ include "betterdb-openeverest.image" . }}).

OpenEverest picks up the Plugin "{{ .Values.plugin.name }}" on its own; reload the OpenEverest UI
and open a Valkey instance to see the BetterDB tab.
{{- if and (not .Values.betterdb.url) (not .Values.betterdb.existingSecret) }}

BetterDB is not configured yet. Set the agent URL and token on the release:

  helm upgrade {{ .Release.Name }} <chart> --namespace {{ .Release.Namespace }} --reuse-values \
    --set betterdb.url=wss://<workspace>.app.betterdb.com/agent/ws \
    --set betterdb.token=<agent token>

(self-hosted: wss://<monitor-host>/api/agent/ws). Or point betterdb.existingSecret at a Secret with
keys `url` and `token`. The token is created in BetterDB under Connections -> Via Agent; the
Settings -> BetterDB panel in OpenEverest shows the values but cannot change them.
{{- end }}

Enabling monitoring on an instance needs the read-connection permission on it. The agent uses
the instance's connection credentials read-only; no pods are restarted.

Logs:
  kubectl logs -n {{ .Release.Namespace }} deploy/{{ include "betterdb-openeverest.fullname" . }} -f
